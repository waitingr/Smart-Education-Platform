# 算法复杂度分析

## 时间复杂度与渐进记号

时间复杂度是算法执行时间随问题规模 n 增长的数量级，用渐进记号描述：

- **大 O 记号 O(f(n))**：存在正常数 c 和 n0，使得当 n ≥ n0 时有 T(n) ≤ c·f(n)，表示**上界**，工程上最常用。
- **大 Ω 记号 Ω(f(n))**：表示**下界**，即算法至少需要的时间。
- **大 Θ 记号 Θ(f(n))**：同时是上界与下界，表示**紧确界**。

因此「快速排序最坏情况是 O(n²)、平均情况是 Θ(n log n)」的表述是准确的：最坏有上界 n²，平均是紧确的 n log n。

分析时的常用化简规则：

1. 忽略常数因子：3n² 记作 O(n²)。
2. 只保留最高阶项：n² + 5n + 100 记作 O(n²)。
3. 加法规则（顺序执行）：T(n) = T1(n) + T2(n) = O(max(f(n), g(n)))。
4. 乘法规则（嵌套执行）：T(n) = T1(n) × T2(n) = O(f(n) × g(n))。
5. 对数底数在渐进意义下不影响阶：log₂n 与 log₁₀n 只差常数倍。

## 常见复杂度量级与增长速率

由低到高依次为：

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)

典型对应：

| 复杂度 | 典型算法 | n=10⁶ 时的量级感受 |
| --- | --- | --- |
| O(1) | 数组随机访问、哈希查找（平均） | 瞬间完成 |
| O(log n) | 折半查找、平衡树查找 | 约 20 次比较 |
| O(n) | 顺序遍历、计数排序 | 10⁶ 次操作 |
| O(n log n) | 归并排序、堆排序、快排平均 | 约 2×10⁷ 次操作 |
| O(n²) | 冒泡、选择、插入排序 | 10¹² 次操作，不可接受 |
| O(2ⁿ) | 朴素递归求斐波那契、子集枚举 | 只能处理 n ≤ 25 左右 |

经验判断：若题目 n ≤ 10⁵，通常期望 O(n log n) 及以下；若 n ≤ 5000，O(n²) 可能可以通过；若 n ≤ 20，才考虑指数级搜索（可用状态压缩优化）。

## 递归式与主定理

分治算法的复杂度常用递归式描述：T(n) = a·T(n/b) + f(n)，其中 a ≥ 1，b > 1。令比较函数 f(n) 与 n^(log_b a)：

1. 若 f(n) = O(n^(log_b a − ε))，则 T(n) = Θ(n^(log_b a))（叶子主导）。
2. 若 f(n) = Θ(n^(log_b a))，则 T(n) = Θ(n^(log_b a) · log n)。
3. 若 f(n) = Ω(n^(log_b a + ε)) 且满足正则条件 a·f(n/b) ≤ c·f(n)，则 T(n) = Θ(f(n))（根主导）。

例：归并排序 T(n) = 2T(n/2) + Θ(n)，a = 2、b = 2，故 n^(log₂2) = n，与 f(n) = n 同阶，属第 2 种情况，T(n) = Θ(n log n)。二分查找 T(n) = T(n/2) + O(1)，属第 2 种情况，T(n) = O(log n)。

## 空间复杂度与原地算法

空间复杂度衡量算法运行所需的辅助空间随 n 的增长，只计算**辅助空间**，不含输入本身。

- 归并排序需要 O(n) 的辅助数组，不是原地排序；
- 堆排序与快速排序（递归栈除外）只需 O(1) 辅助空间，属原地排序；
- 递归算法的空间复杂度需计入调用栈深度：快速排序最坏递归深度 O(n)，优化方式是「先递归较短区间、较长区间尾递归」，可把栈深压到 O(log n)。

## 摊还分析

摊还分析研究「一系列操作」的平均代价，而不是单次最坏代价。三种常用方法：聚合分析、记账法、势能法。

典型例子：动态数组（C++ vector、Python list）的扩容。单次扩容需要复制全部元素，代价 O(n)，但每次扩容容量翻倍，n 次插入的总代价为 O(n)，因此单次插入的**摊还复杂度**为 O(1)。这说明「偶尔慢一次」不影响整体效率。

并查集的路径压缩加按秩合并，单次操作的摊还复杂度为 O(α(n))，其中 α 是反阿克曼函数，实际可视为常数。

## 常见误区

1. **把最好情况当平均情况**：快速排序最好 O(n log n)、平均 O(n log n)、最坏 O(n²)，三者都要能说清。
2. **忽略常数与 IO**：O(n) 的哈希查找在常数很大或缓存不友好时可能慢于 O(log n) 的折半查找。
3. **嵌套循环一律当 O(n²)**：若内层循环次数依赖外层（如 for i in range(n): for j in range(i)），总次数是 n(n−1)/2，仍然是 O(n²)；但如果内层是 while 且指针单调移动，总量可能是 O(n)（双指针技巧）。
4. **空间复杂度漏算递归栈**：递归实现的二叉树遍历空间复杂度是 O(h)，h 为树高，不是 O(1)。
5. **认为 O 记号能精确比较算法**：O 只给出上界，两个都是 O(n²) 的算法常数可能差 10 倍。
