# 树与二叉树

## 树的基本术语

树是 n（n ≥ 0）个结点的有限集合，有且仅有一个根结点，其余结点可分为若干个互不相交的子树。常用术语：

- **结点的度**：结点拥有的子树个数；树的度是各结点度的最大值。
- **层次与深度**：根为第 1 层，树中结点的最大层次称为树的深度（高度）。
- **叶子结点**：度为 0 的结点。
- **路径长度**：路径上边的数目。

树的三条常用性质：结点数 = 总度数 + 1；度为 m 的树中第 i 层最多有 m^(i−1) 个结点；高度为 h 的 m 叉树最多有 (m^h − 1)/(m − 1) 个结点。

## 二叉树的重要性质

二叉树是每个结点至多有两棵子树、且子树有左右之分的有序树。五条必记性质：

1. 第 i 层最多有 2^(i−1) 个结点（i ≥ 1）。
2. 深度为 k 的二叉树最多有 2^k − 1 个结点（k ≥ 1）。
3. 对任何非空二叉树，若叶子数为 n₀、度为 2 的结点数为 n₂，则 **n₀ = n₂ + 1**。
4. 具有 n 个结点的完全二叉树深度为 ⌊log₂n⌋ + 1。
5. 完全二叉树按层序从 1 开始编号，则结点 i 的左孩子为 2i、右孩子为 2i+1、双亲为 ⌊i/2⌋（下标从 1 开始；若从 0 开始则为 2i+1、2i+2、⌊(i−1)/2⌋）。

**满二叉树**：每层都达到最大结点数。**完全二叉树**：只有最下面两层结点度可小于 2，且最下层结点集中在左侧。完全二叉树适合用顺序存储（数组），因为下标关系天然反映父子关系；一般二叉树用顺序存储会浪费大量空间，应使用链式存储（二叉链表，每个结点含 lchild、data、rchild）。

## 二叉树的四种遍历

- **先序（根左右）**、**中序（左根右）**、**后序（左右根）**：递归实现时间 O(n)、空间 O(h)（h 为树高，即递归栈深度）。
- **层序**：借助队列，逐层访问，时间 O(n)、空间 O(w)（w 为最大层宽）。

关键性质：**中序序列 + 先序（或后序）序列可以唯一确定一棵二叉树**；但先序 + 后序不能唯一确定。由先序和中序重建二叉树是经典分治题：先序首元素为根，在中序中定位根即可划分左右子树，递归处理，时间 O(n)（配合哈希表定位根）。

非递归遍历需要显式使用栈。以中序为例：一路向左压栈，弹出访问，再转向右子树。

Morris 遍历可以把空间降到 O(1)：利用叶子结点的空右指针建立线索，遍历后恢复，是不允许使用额外空间的场景下的标准解法。

## 二叉排序树（BST）

二叉排序树满足：左子树所有结点值 < 根值 < 右子树所有结点值，且左右子树也是 BST。

- 查找、插入、删除的平均时间为 O(log n)，**最坏为 O(n)**（当插入序列有序时退化为单支树，等同链表）。
- **中序遍历 BST 得到递增序列**，这是判断一棵树是否为 BST 的最简洁方法。
- 删除结点分三种情况：叶子直接删；只有一个孩子用孩子顶替；有两个孩子则用中序前驱（或后继）替换其值，再删除前驱结点。

BST 的平均查找长度 ASL 取决于树的形态，与插入顺序有关，这是它不如平衡树的根本原因。

## 平衡二叉树（AVL）与红黑树

AVL 树要求任意结点的左右子树高度差（平衡因子）绝对值不超过 1。插入后失衡有四种情形，通过四种旋转恢复平衡：

- LL 型：一次右旋；
- RR 型：一次左旋；
- LR 型：先左旋后右旋；
- RL 型：先右旋后左旋。

AVL 树查找、插入、删除均为 O(log n)，代价是维护平衡的旋转开销，适合查询远多于修改的场景。

**红黑树**通过颜色约束（根黑、红结点子结点必黑、任一结点到叶子的黑高相同）保证最长路径不超过最短路径的 2 倍，因此高度为 O(log n)。它牺牲了严格平衡换取更少的旋转次数，插入删除性能优于 AVL，是 Java TreeMap、C++ std::map、Linux 内核 rbtree 的选择。

## 堆与优先队列

堆是满足「堆序性质」的完全二叉树：大根堆中每个结点值 ≥ 其子结点值，小根堆反之。用数组存储，下标从 0 开始时，结点 i 的孩子为 2i+1 与 2i+2，双亲为 ⌊(i−1)/2⌋。

- 建堆：从最后一个非叶结点（⌊n/2⌋−1）开始自底向上下沉，总代价 O(n)，而不是 O(n log n)。
- 插入：放在末尾后上浮，O(log n)。
- 删除堆顶：末尾元素移到堆顶后下沉，O(log n)。

典型应用：Top-K 问题（求最大 K 个元素用小根堆，维护大小为 K 的堆，时间 O(n log K)）、堆排序、优先队列、Dijkstra 与 Prim 的优先队列优化、定时任务调度。

## 哈夫曼树与编码

哈夫曼树是带权路径长度（WPL）最小的二叉树。构造方法：每次从森林中取权值最小的两棵树合并，新结点权值为二者之和，重复至只剩一棵树。n 个叶子的哈夫曼树共有 2n−1 个结点，没有度为 1 的结点。

由哈夫曼树得到的哈夫曼编码是**前缀编码**（任一编码都不是另一编码的前缀），可保证解码无歧义，且平均码长最短。它广泛用于文件压缩（如 DEFLATE 中的一部分）与信源编码。

## 常见错误

1. **完全二叉树下标公式用错**：0 起始与 1 起始的公式不同，写代码前必须确认。
2. **n₀ = n₂ + 1 记反**：正确形式是叶子数比度为 2 的结点数多 1。
3. **BST 删除有两个孩子的结点时直接删除**：必须先找中序前驱/后继替换值。
4. **用 BST 当哈希表用**：有序插入会退化成链表，需要平衡树或随机化（Treap、跳表）。
5. **层序遍历不记录层边界**：需要按层输出时要在每轮循环前记录当前队列长度。
6. **堆排序建堆复杂度写成 O(n log n)**：自底向上建堆是 O(n)，整体排序才是 O(n log n)。
