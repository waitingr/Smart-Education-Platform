# 图论基础与最短路径

## 图的存储结构

图 G = (V, E) 由顶点集与边集构成。按边是否有方向分为有向图与无向图，按边是否带权分为带权图与无权图。

- **邻接矩阵**：n×n 二维数组，A[i][j] 表示是否存在边或边权。空间 O(n²)，判断两点是否相邻 O(1)，适合稠密图。无向图的邻接矩阵关于主对角线对称，可只存一半。
- **邻接表**：每个顶点维护一个出边链表（或动态数组），空间 O(n + e)，适合稀疏图；判断两点是否相邻需要遍历该顶点的边表，最坏 O(n)。
- **十字链表 / 邻接多重表**：分别针对有向图与无向图的边操作优化，便于删除边。

工程选型：n ≤ 1000 且边密集用邻接矩阵；n 很大、e 与 n 同阶用邻接表。稀疏图上做 Dijkstra 必须用邻接表 + 优先队列，否则 O(n²) 的时间会超时。

## 图的遍历：DFS 与 BFS

**深度优先搜索（DFS）**沿一条路径尽可能深入，回溯后再换分支。递归实现简洁，但递归深度可能达到 n，链状图上会栈溢出，应改用显式栈。DFS 可用于求连通分量、判断环、拓扑排序、割点与桥（Tarjan 算法）。

**广度优先搜索（BFS）**按层扩展，借助队列实现，第一次到达某点时经过的边数一定最少，因此**无权图的最短路径必须用 BFS**（而不是 DFS）。

两者时间复杂度均为 O(n + e)（邻接表）或 O(n²)（邻接矩阵）。必须使用 visited 标记，否则在无向图中会立即来回震荡。

## 最小生成树

最小生成树（MST）是连通带权无向图中边权和最小的生成树，含 n 个顶点、n−1 条边。两个经典算法：

- **Prim 算法**：从任一顶点出发，每次把「连接已选集合与未选集合的最小边」加入。朴素实现 O(n²)，适合稠密图；用优先队列可优化到 O(e log n)。
- **Kruskal 算法**：把所有边按权值升序排序，依次加入不构成环的边，用并查集判环。复杂度由排序主导，O(e log e)，适合稀疏图。

两者都基于贪心，正确性由**切分性质**保证：对任意切分，横跨切分的最小权边必定属于某棵 MST。

## 最短路径

**Dijkstra 算法**解决**非负权**单源最短路径。维护已确定集合 S，每次取出距离最小的未确定顶点并松弛其邻边。

- 朴素实现 O(n²)，适合稠密图；
- 优先队列 + 邻接表 O((n + e) log n)，适合稀疏图；
- **不能处理负权边**：Dijkstra 的正确性依赖「已选定的最短距离不会再被更短路径更新」，负权会破坏这一前提。

**Bellman-Ford 算法**允许负权边，对每条边做 n−1 轮松弛，复杂度 O(n·e)；若第 n 轮仍能松弛，说明存在负权环。SPFA 是其队列优化版本，平均快但最坏仍为 O(n·e)。

**Floyd-Warshall 算法**求任意两点间最短路径（全源），三重循环动态规划，复杂度 O(n³)、空间 O(n²)，实现极简，适合 n ≤ 500 的稠密图。它同样支持负权边（但不能有负权环）。核心转移方程：

```
for k in range(n):
    for i in range(n):
        for j in range(n):
            d[i][j] = min(d[i][j], d[i][k] + d[k][j])
```

注意循环顺序必须是 k 在最外层，且 k 表示「允许经过的中间顶点集合逐步扩大」，顺序写错会得到错误结果。

## 拓扑排序与关键路径

**拓扑排序**对有向无环图（DAG）给出线性序，使每条有向边 u→v 都满足 u 排在 v 之前。Kahn 算法：统计入度，把入度为 0 的点入队，逐个出队并删除其出边，若最终输出的顶点数小于 n，则图中存在环。复杂度 O(n + e)。

应用：课程先修关系、编译器的表达式依赖、任务调度、包管理器的依赖解析。

**关键路径**（AOE 网）用于工程工期估算：先求事件最早发生时间 ve 与最迟发生时间 vl，活动的时间余量 = vl − ve − 活动持续时间，余量为 0 的活动即关键活动，其构成的路径为关键路径。缩短关键路径上的活动才能缩短总工期。

## 常见错误

1. **有负权边时使用 Dijkstra**：结果错误且不报错，是隐蔽性最强的错误之一。
2. **Floyd 三重循环顺序写错**，把 k 写在最内层。
3. **BFS 求最短路径时忘记记录距离**，只用 visited 标记，导致无法输出路径长度。
4. **无向图存边只存一半**：邻接表中 A→B 存了但 B→A 没存。
5. **并查集判环时忘记路径压缩**，在长链上会退化为 O(n)。
6. **拓扑排序只处理入度为 0 的初始结点**，未在出队时及时递减相邻点入度，导致漏点。
7. **把「最小生成树」与「最短路径树」混为一谈**：MST 使边权和最小，最短路树使源点到各点距离最小，两者一般不同。
