# 线性表、栈与队列

## 线性表的定义与顺序存储

线性表是由 n（n ≥ 0）个数据元素构成的有限序列，除首元素外每个元素有且仅有一个前驱，除尾元素外有且仅有一个后继。

**顺序表**用一组地址连续的存储单元依次存放元素，逻辑相邻即物理相邻。设基址为 LOC(a₁)、每个元素占 c 个单元，则第 i 个元素的地址为 LOC(aᵢ) = LOC(a₁) + (i−1)·c，因此**按下标随机访问是 O(1)**。

顺序表操作的复杂度：

- 按位查找、按值查找中的随机访问：O(1)；
- 插入：平均需移动 n/2 个元素，O(n)；
- 删除：平均需移动 (n−1)/2 个元素，O(n)；
- 动态扩容：容量不足时申请更大空间并整体复制，摊还 O(1)。

插入操作的正确顺序是「先移动、后插入」：从表尾开始，把第 n 到第 i 个元素依次后移一位，再写入新元素。若从前往后移动，会覆盖尚未移动的数据。

## 链式存储：单链表、双链表、循环链表

**单链表**用指针域 next 指向后继结点，结点在内存中可以离散分布。带头结点（哨兵）的单链表可以让插入删除逻辑统一，无需对表头特判，是工程上的推荐写法。

- 按序号查找：需从头遍历，O(n)；
- 已知前驱指针的插入、删除：O(1)；
- 表头插入：O(1)。

**双链表**增加 prior 指针，可以在 O(1) 时间内删除给定结点本身（单链表删除给定结点需先找前驱）。典型的「在 p 之后插入 s」需要修改四个指针，顺序不能错：

```
s->prior = p;
s->next  = p->next;
p->next->prior = s;
p->next  = s;
```

**循环链表**尾结点的 next 指向头结点，从任意结点出发都能遍历全表，适合约瑟夫环、轮转调度等场景。

## 栈及其应用

栈是只允许在一端（栈顶）进行插入和删除的线性表，遵循**后进先出（LIFO）**原则。基本操作：push、pop、top、isEmpty，时间复杂度均为 O(1)。

典型应用：

1. **括号匹配**：遇左括号入栈，遇右括号出栈比对，最后栈空则合法。
2. **表达式求值**：中缀转后缀（调度场算法），再用栈求值。
3. **函数调用与递归**：系统调用栈保存返回地址与局部变量，递归深度决定栈空间。
4. **深度优先搜索的非递归实现**：用显式栈替代递归。
5. **撤销操作、浏览器前进后退**：双栈模型。

## 队列与循环队列

队列是只允许在一端插入（队尾）、另一端删除（队头）的线性表，遵循**先进先出（FIFO）**原则。

顺序队列存在「假溢出」：队头指针后移导致前方空间不可用。解决办法是**循环队列**，用取模运算让下标回绕：

- 入队：`rear = (rear + 1) % MAXSIZE`
- 出队：`front = (front + 1) % MAXSIZE`
- 队空条件：`front == rear`
- 队满判断：牺牲一个单元，`(rear + 1) % MAXSIZE == front`，此时最多存放 MAXSIZE−1 个元素；或额外维护 size/count 变量。

循环队列的队内元素个数为 `(rear − front + MAXSIZE) % MAXSIZE`。

应用场景：BFS 层序遍历、任务调度、生产者消费者缓冲、打印队列。

**双端队列（deque）**两端都可以插入删除，常用于滑动窗口最值问题（单调队列，O(n)）。

## 复杂度对比与选型

| 操作 | 顺序表 | 单链表 | 循环队列 |
| --- | --- | --- | --- |
| 随机访问 | O(1) | O(n) | 不支持 |
| 头部插入/删除 | O(n) | O(1) | — |
| 尾部插入 | O(1) 摊还 | O(n) 需遍历 | O(1) |
| 按值查找 | O(n) | O(n) | — |
| 存储密度 | 高（无指针开销） | 低（每结点多 1~2 个指针） | 高 |

选型建议：读多写少且需要随机访问用顺序表；频繁在中间/头部插入删除用链表；需要严格 FIFO 且容量固定用循环队列。

## 常见错误

1. **链表删除后未释放内存**：C/C++ 中 `free`/`delete` 遗漏会造成内存泄漏；Python/Java 由 GC 管理但要注意仍持有引用。
2. **头结点与首元结点混淆**：带头结点时，空表条件是 `head->next == NULL`，而不是 `head == NULL`。
3. **循环链表遍历缺少终止条件**：应判断 `p != head` 而非 `p != NULL`，否则死循环。
4. **顺序表插入忘记判满、删除忘记判空**，导致数组越界。
5. **循环队列入队未判满**，会覆盖已有数据或产生 front 与 rear 相等而被误判为空。
6. **在单链表中删除结点时丢失前驱**：必须先保存 `pre->next`，再修改指针，最后释放。
