# 研究前沿：大模型与代码智能

## 研究主题概览

围绕「人工智能 + 计算机教育」方向，近三年（2022—2025）的研究主要集中在四个主题：

1. **代码大模型与程序理解**：Codex、StarCoder、CodeLlama、DeepSeek-Coder、Qwen2.5-Coder 等模型在代码补全、代码摘要、缺陷检测任务上持续刷新基准。评测集以 HumanEval、MBPP、SWE-bench 为主。
2. **检索增强生成（RAG）**：通过外部知识库约束生成内容，缓解幻觉。核心环节包括文档解析、语义分块、混合检索（BM25 + 稠密向量）、重排序与引用归因。
3. **教育场景智能体**：智能备课、自动批改、学情诊断、个性化学习路径，强调多轮对话与可解释的评分依据。
4. **学科知识图谱**：把教材概念、先修关系、常见错误建模为图结构，用于路径规划与错因推断。

## 关键方法与技术路线

**微调路线（SFT / LoRA）**：在通用基座模型上用学科指令数据做监督微调。LoRA 通过低秩分解只训练少量参数（通常 0.1%~1% 参数量），显著降低显存与成本，适合实验室与高校场景。典型超参：r = 8~64，alpha = 2r，学习率 1e-4 ~ 2e-4，3~5 个 epoch。

**检索增强路线（RAG）**：无需训练即可注入领域知识，更新知识只需更新索引。工程要点是分块策略（按章节/语义而非固定长度）、混合检索（稀疏 + 稠密）、以及**引用可追溯**——每个生成片段都能回指到原文位置。

**智能体路线（Agent）**：把复杂任务拆成多步工作流，每步可调用检索、计算工具或外部 API，支持条件分支与失败重试。多智能体协作（Planner + Retriever + Critic）可提升复杂问题的稳定性。

**评估路线**：单一 BLEU/ROUGE 已不足以评价教育场景输出，当前更关注**忠实度（faithfulness）**、**引用准确率**、**学科规范符合度**与**教师人工评分一致性**。

## 发展趋势

- **从「通用模型」到「学科垂类模型」**：垂直领域通过领域继续预训练 + 指令微调 + RAG 三件套，在专业术语与规范上明显优于通用模型。
- **从「单轮问答」到「工作流闭环」**：产品形态从聊天框转向「备课—授课—作业—诊断—辅导」的教学闭环。
- **从「黑盒生成」到「可核验生成」**：引用标注、置信度提示、生成内容标识成为教育产品的合规刚需。
- **多模态融合**：图文混排教材、手写作业识别、实验数据图表理解，是下一阶段的主要增量。

## 研究空白与机会

1. **学科规范的自动校验**：现有工作多关注「答得对」，较少关注「格式符合学科规范」（如复杂度分析必须标注、参考文献必须符合 GB/T 7714）。
2. **小样本学科微调数据构建**：高质量学科指令数据稀缺，如何用教材自动合成指令数据仍是开放问题。
3. **可解释的学情诊断**：从「分数统计」走向「知识点级归因」，需要知识图谱与作答日志的联合建模。
4. **人机协同的教学设计**：AI 生成教案后教师的修改行为数据，是改进模型的重要反馈信号，目前研究较少。

## 对本科生的可行切入点

- 复现一个 RAG 教学问答系统，重点做**引用可追溯**与**幻觉率评测**；
- 用 LoRA 在 1000 条学科指令数据上微调 7B 模型，对比微调前后的学科术语准确率；
- 构建课程知识图谱（概念 + 先修边 + 易错边），用于个性化路径推荐；
- 设计自动批改的评分点拆解方法，并与教师人工评分做一致性分析（Kappa 系数）。
