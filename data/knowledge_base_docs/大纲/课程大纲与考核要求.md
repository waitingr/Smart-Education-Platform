# 数据结构与算法课程大纲与考核要求

## 课程定位与目标

本课程是计算机科学与技术专业的核心专业基础课，共 64 学时（理论 40、实验 24），4 学分，先修课程为「程序设计基础（C/Python）」与「离散数学」。

课程目标（对应工程教育认证的毕业要求指标点）：

1. **知识目标**：掌握线性表、栈、队列、树、图等典型数据结构的逻辑结构、存储结构与基本运算实现。
2. **能力目标**：能够针对实际问题选择合适的数据结构，设计算法并用渐进分析评估效率（支撑「问题分析」与「设计/开发解决方案」指标点）。
3. **素养目标**：形成严谨的工程规范意识与学术诚信意识，能独立完成实验并规范撰写报告。

## 重点与难点

**重点**：算法复杂度分析、链表指针操作、二叉树遍历与递归、图的存储与最短路、排序算法对比、哈希冲突处理。

**难点**：递归思维与递归转非递归、图算法的正确性条件（Dijkstra 的非负权前提）、平衡树的旋转、摊还分析。

教学建议：难点章节采用「可视化演示 + 手工追踪 + 代码实现」三段式；每章配套 1 个编程实验与 1 组在线自测题。

## 考核方式

| 考核环节 | 权重 | 说明 |
| --- | --- | --- |
| 平时作业 | 15% | 每章 1 次书面作业，迟交扣 10%/天 |
| 编程实验 | 25% | 共 8 次，需提交源码 + 实验报告 + 复杂度分析 |
| 期中测验 | 10% | 闭卷，覆盖第 1~4 章 |
| 期末机考 | 40% | 在线编程 3 题 + 客观题，允许查阅教材 |
| 课堂参与 | 10% | 提问、讨论、同伴互评 |

**实验报告规范**：须包含问题描述、数据结构设计、算法描述与复杂度分析、测试用例（含边界用例）、运行结果截图、问题与反思。报告缺失复杂度分析者，该项按 60% 计分。

## 能力达成度评价

每学期末对三个指标点做达成度计算：

- 指标点 1（问题分析）：以期末机考中「建模与选型」类题目平均得分率衡量，达成阈值 0.65。
- 指标点 2（设计/开发解决方案）：以 8 次编程实验的平均分衡量，达成阈值 0.70。
- 指标点 3（工程规范与诚信）：以实验报告规范性评分与查重结果衡量，重复率超过 30% 直接判定不达成。

评价结果用于下一轮课程持续改进（CDIO 闭环）。

## 常见学习困难与支持

根据近三届学情数据，学生最容易在以下三类问题上失分：

1. **复杂度判断**：把嵌套循环一律视为 O(n²)，或将快排最坏复杂度写成 O(n log n)。
2. **链表/递归的指针与边界**：删除结点后未释放、递归缺终止条件、二分边界混用。
3. **图算法的适用条件**：负权图误用 Dijkstra、Floyd 循环顺序写错。

对应支持措施：平台提供知识点自测、错题归因、个性化学习路径与分步讲解；教师可基于学情诊断报告进行针对性复习。
