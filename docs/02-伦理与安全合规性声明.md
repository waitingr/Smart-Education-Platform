## 一、三项核心承诺

参赛团队就本作品的数据使用与内容生成作出如下承诺，并在系统实现中落到了具体机制上（非仅口头承诺）：

### 承诺一：不使用未经脱敏的真实个人数据

本作品**不采集、不存储、不使用任何未经脱敏的真实个人数据**（学生、患者、案件当事人等敏感信息）。

落实方式：

1. **演示数据全部为程序生成**：仓库内 55 名学生、196 份作业提交、241 条使用记录均来自 `scripts/seed_demo.py`，姓名由姓氏字库与名字字库组合生成，学号为顺序编号，邮箱为 `student<学号>@smartedu.cn` 形式，**不对应任何真实自然人**。
2. **知识库文档为自编教材化内容**：`data/knowledge_base_docs/` 下 11 份文档由团队依据公开教材知识体系自行撰写，不含真实学生作业、不含未公开的科研数据、不含受版权保护的原文长段复制。
3. **上传功能有明确提示**：附件上传与知识库上传页面均标注"请勿上传含真实学生身份信息的材料"；`doc_parser` 解析内容仅用于当次问答或索引，不做跨用户画像。
4. **无第三方埋点**：不使用任何第三方统计 SDK，不向外部回传用户行为数据；`UsageEvent` 仅记录事件类型、智能体 id、耗时、是否降级，**不记录问题原文到外部**。
5. 如后续接入真实教学数据，须先经所在单位伦理审查、完成去标识化（删除姓名/学号/身份证/联系方式），并在部署文档中登记数据处理责任人。

### 承诺二：不生成伪造学术数据、虚假文献或违反学术伦理的内容

本作品**不生成伪造学术数据、虚假文献，不提供任何违反学术伦理与科研诚信的生成结果**。

落实方式：

1. **学术诚信守卫（`agents.check_academic_integrity`）**：在批改、写作、答疑等入口做模式检测，命中"编造/伪造/虚构/捏造/杜撰 + 文献/数据/实验/引用"等组合即**拒绝生成**，返回拦截原因并给出合规替代路径。该机制在 `scripts/smoke_test.py` 中有专门用例（第 5、7 节）验证。
2. **不代写主体论证**：学术写作智能体只提供框架、结构、语言润色与**GB/T 7714—2015** 著录规范检查，明确不生成论文主体论证、不生成"看似合理"的参考文献条目。
3. **引用必须来自知识库**：回答中的每个 `[n]` 都由检索结果生成，`AgentContext.verify_citations` 会剔除未在知识库中出现的编号，并记录"引用命中 x/y 条"；**不存在凭空编造的参考文献**。
4. **数据不虚构**：科研数据分析智能体的统计结果全部来自用户上传文件的真实计算（`doc_parser.parse_tabular` + `numeric_summary`），缺失数据时明确提示"未识别到可统计的数值列"，而不是补一个看起来很合理的数。
5. **不确定性显式表达**：知识库未覆盖时，回答明确写"知识库中暂未检索到与该问题直接相关的内容"并给出补充建议，不强行编造答案。

### 承诺三：系统设置明显的"AI 生成内容"标识

本作品在**所有 AI 生成内容的可见位置**设置了明显标识。

落实方式：

1. **数据层**：`Message.ai_generated` 字段与接口返回的 `ai_generated` / `ai_label` 字段（`Config.AI_CONTENT_LABEL` = "本内容由 AI 生成，仅供参考"）贯穿所有生成接口。
2. **界面层**：
   - 每条 AI 回答卡片底部固定显示"AI 生成内容，请核查引用后使用"；
   - 结果卡片顶部显示生成后端徽标（本地大模型 / 讯飞星火 / 在线大模型 / **离线检索模式**）；
   - 对话页底部常驻"AI 生成内容仅供教学参考"；
   - 导出的 Markdown 文件首行自动写入 AI 生成声明。
3. **降级层**：未接入大模型时，回答顶部显示醒目的"当前为**离线检索模式**（未连接大模型），以下内容由学科知识库原文按工作流结构化编排生成"，**不把检索摘录伪装成大模型输出**。
4. **批改场景**：评分结果明确标注"建议分，需教师确认"，不替代教师评价。

## 二、数据安全与隐私保护

| 事项 | 做法 |
| --- | --- |
| 账号口令 | bcrypt 加盐哈希存储（`User.set_password`），不存明文；口令强度在注册时校验 |
| 会话凭证 | Flask Session（签名 Cookie）+ API Token 双通道；Token 有过期时间（`token_expires`） |
| 权限控制 | 角色区分 `student` / `teacher` / `admin`；教师专属接口用 `@teacher_required` 装饰器；知识库上传、学生信息管理仅教师可用 |
| 上传文件 | 保存前做文件名净化（`re.sub(r'[<>:"/\\|?*]', '_')`）与重名冲突处理；限制类型与解析长度（`MAX_ATTACHMENT_TEXT_LENGTH`） |
| 知识库删除 | 删除文档后立即重建索引，避免残留片段继续被检索 |
| 日志 | 仅打印异常堆栈与启动信息，不打印用户问题原文与口令；`_SafeStream` 防止控制台异常连带影响接口 |
| 数据传输 | 生产部署建议置于 HTTPS 反向代理之后（详见部署说明） |

## 三、内容安全与使用边界

1. **不提供违法违规内容**：学科限定为计算机科学与技术课程内容，工作流提示词限定在学科范围内。
2. **学术用途边界**：明确"AI 辅助"而非"AI 代写"；批改与写作场景均有人机确认环节。
3. **错误可纠正**：引用可点开核查原文；回答可反馈"需改进"，反馈进入 `Feedback` 表并计入看板。
4. **不误导**：所有能力状态（是否接入大模型、是否降级、知识库规模）在界面上如实展示，可通过 `/api/v1/health/stack` 核验。

## 四、知识产权

1. 平台代码（Flask 后端、原生 JS 前端、训练脚本）由参赛团队自行开发，未复制任何已发布产品的代码。
2. 知识库文档为团队依据公开教材知识体系**自行撰写**的教学化内容，非原文摘录；引用他人观点处已按 GB/T 7714 标注来源。
3. 第三方依赖均为开源许可（Flask / SQLAlchemy / numpy / pypdf / python-docx / openpyxl 等），遵守各自许可协议；基础模型使用 **Qwen3-VL-8B-Instruct（Apache-2.0）** 的本机 Ollama 量化版本（`qwen3-vl:8b`），严格遵守其模型许可与服务条款；如另行接入讯飞星火等云端服务，同样遵守对应服务条款。
4. 参赛团队对参赛作品享有完全知识产权，无权利瑕疵及归属争议。

## 五、风险与已采取的缓解措施

| 风险 | 缓解措施 |
| --- | --- |
| 大模型幻觉 | RAG 强约束 + 引用存在性校验 + 知识库未覆盖时明确说明 |
| 检索召回错误 | 多信号融合打分（BM25/向量/覆盖率/短语/权威度），并在知识库页面提供"检索自测"，便于人工抽检 |
| 学术不端滥用 | 学术诚信守卫 + 不代写主体论证 + 批改结果需教师确认 |
| 数据泄露 | 最小化采集、去标识化演示数据、角色权限控制、上传净化 |
| 评审环境无 GPU/无网络 | 离线检索模式保证功能可演示，且界面如实标注状态 |
| 用户误信 AI 输出 | 全链路 AI 标识 + "请核查引用"提示 + 反馈闭环 |
